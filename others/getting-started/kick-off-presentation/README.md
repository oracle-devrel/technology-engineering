# Kick-Off Your Oracle Cloud Journey Presentation
 
Welcome to the Oracle Cloud Journey Kick-Off. In this session, we will explore the first steps to get started with Oracle Cloud Infrastructure (OCI), from accessing your cloud environment and understanding its core services to setting up the foundations for secure, scalable workloads. Together, we will establish a clear path for your cloud adoption journey and help you confidently begin realizing the value of OCI.

Review Date: 25.09.2026
 
# When to use this asset?
 
This presentation is ideal at the beginning of an Oracle Cloud Infrastructure (OCI) adoption journey. It can be used to align business and technical stakeholders, introduce teams to the OCI environment, and clarify the initial activities required to establish a secure and well-governed cloud foundation. It is especially useful before onboarding new workloads, launching a migration initiative, or starting a cloud enablement programme.

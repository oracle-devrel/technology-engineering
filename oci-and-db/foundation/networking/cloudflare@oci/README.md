# Cloudflare@Oracle Cloud Infrastructure

Cloudflare@OCI, a strategic partnership between Oracle Cloud Infrastructure (OCI) and Cloudflare designed to help organizations accelerate and secure modern applications and AI workloads at scale.

As businesses evolve, expectations have changed. Users now demand fast, dependable digital experiences delivered seamlessly across the globe, while cyber threats are increasing in both scale and complexity. Meanwhile, application architectures are becoming more distributed, spanning both cloud and on premises.

Cloudflare@OCI brings together OCI’s high-performance cloud and Cloudflare’s global edge network to deliver a unified solution that improves performance, strengthens security, and simplifies the purchase and deployment of edge services. It also helps organizations implement the infrastructure required to support secure, high-performance, production-ready AI applications.

Cloudflare @ OCI lets OCI customers purchase and manage Cloudflare service bundles in the OCI Console using UCM credits.

Oracle Cloud Infrastructure (OCI) provides a platform capability that integrates strategic partner offerings directly into the Oracle Cloud Console. This capability presents partner solutions alongside native OCI services, providing a unified customer experience. OCI customers can purchase partner offerings using Universal Credits Model (UCM) credits.

## Use Cases

- Cloudflare as the Edge for OCI — Anycast front door for OCI-hosted apps; every request hits the nearest of 330+ PoPs, no DNS-based failover lag.

- Multi-layer DDoS protection in front of OCI — L7 (DDoS for Web Apps), L4 (Spectrum for TCP/UDP) — 500 Tbps capacity, 0–3 sec mitigation, no backhaul to scrubbing centers.

- Global load balancing + 100% uptime SLA — Inter- and intra-DC load balancing with instant Anycast failover from unhealthy OCI origins (no TTL waits).

- Argo Smart Routing — Real-time path optimization across Cloudflare's backbone for ~30% faster delivery to OCI origins.

- API & app traffic shaping — Advanced Rate Limiting (API-centric, not IP-based) to protect OCI-hosted APIs from abuse, scraping, brute force, and L7 DDoS.

- Authoritative DNS (Foundation DNS) — DNSSEC, DNS over HTTP, recursive + authoritative in front of OCI workloads

- Reduce OCI egress costs with CDN + Cache Reserve — Tiered caching + R2-backed persistent cache (up to 30 days) shields OCI origins and cuts egress fees to zero on cached content.

### User Experience

- From the Console menu, navigate to Identity & Security → Partner Offerings → Cloudflare @ OCI. (The same destination is also reachable through the Console search.)
- On the landing page, view the list of four bundles, compare them side-by-side, and review key details (entitlements, monthly price, overage rates).
- Click a bundle name to see its full details and feature breakdown.
- Review and accept the Cloudflare service agreements (service terms / EULA) before continuing.
- Select the bundle via the radio button and click "Provision" to begin the purchase.
- Confirm the purchase.
- Receive a purchase confirmation that includes the fulfilment SLA and a follow-up email pointer.

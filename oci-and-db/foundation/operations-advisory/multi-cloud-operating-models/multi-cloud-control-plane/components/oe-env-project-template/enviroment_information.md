# Project environment information

This file is generated from the validated
`project-foundation-handoff.json` during project onboarding. Before giving the
repository to the Project Team, the platform administrator must confirm that it
identifies the approved project, environment, region, compartments, VCN,
role-based subnets, source workflow, run, commit, and Terraform state keys.

The generated project repository replaces this page with the complete handoff
content. If this placeholder is still present, onboarding is not complete and
no infrastructure request should be merged.

This document is for people and may be used by optional request tools to suggest
form values. Deployment workflows use the JSON manifests in the cloud and
region directories. Never add credentials, passwords, private keys, or tokens
to this file.

# Cloud Guard Activity Reporter

Last reviewed: 2026-09-04

# What is this asset?

Cloud Guard Activity Reporter is a Go tool to track, summarize, and export Oracle Cloud Guard activity.

Features:
* Filter by compartment, region, resource type, or risk level 
* Generate CSV reports 
* Quick insights on recent security problems
  
# How to use this asset?

Review the project and its usage instructions in the [Cloud Guard Activity Reporter repository](https://github.com/eugsim1/cloudguard-activity-reporter).

# OCI Resource Analytics

Reviewed: 2026-09-04

OCI Resource Analytics is an Oracle Cloud Infrastructure service that provides centralized visibility and analysis of cloud resources across compartments, regions, and tenancies. It helps organizations inventory, monitor, and analyze their OCI assets, enabling better governance, resource optimization, and operational insights through aggregated metadata and analytics.

As OCI environments grow, it becomes difficult to maintain an accurate inventory of resources, identify unused or misconfigured assets, and understand resource distribution across the organization. OCI Resource Analytics addresses this by providing a unified view of cloud resources, enabling teams to discover assets, analyze resource usage and trends, improve governance, and make informed decisions about optimization, compliance, and cost management.

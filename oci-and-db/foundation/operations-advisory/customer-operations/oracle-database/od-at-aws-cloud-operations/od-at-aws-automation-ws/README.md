# Oracle Database@AWS Automation Workshop

Reviewed: 2026-09-04

## What is this asset?

This workshop enables OCI users to automate Oracle Database@AWS operations with Infrastructure as Code (IaC) and to run them using GitOps at scale.

For Cloud Operators, Admins, Architects, DevOps and Center of Excellence teams.

Use it to learn more about Oracle Database@AWS automation and typical Day 1 and Day 2 operations.

## How to use this asset?

Read the workshop PDF in the files folder: [Oracle Database@AWS Automation Workshop](./files/Public_OD@AWS_Automation_v0.1.pdf).

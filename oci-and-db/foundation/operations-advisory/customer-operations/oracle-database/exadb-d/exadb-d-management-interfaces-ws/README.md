# Oracle Exadata Database Service on Dedicated Infrastructure (ExaDB-D) Management Interfaces Workshop

Reviewed: 2026-09-04

## What is this asset?

This workshop enables OCI users to run Exadata Database Service on Dedicated Infrastructure (ExaDB-D) Management Interfaces to understand the different ways to manage the Cloud Service with the available cloud tooling. 

For Cloud Operators, Admins, Architects, DevOps and Center of Excellence teams.

Use it to know more about ExaDB-D Management Interfaces.

Read in the files folder the workshop in PDF [ExaDB-D - Management Interfaces Deep Dive Worksho.p](./files/Public_0_OCI_ExaDB_Management_Interfaces_v1.0.pdf).

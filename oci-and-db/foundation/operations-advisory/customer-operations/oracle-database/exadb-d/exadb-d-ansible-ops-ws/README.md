# Oracle Exadata Database Service on Dedicated Infrastructure (ExaDB-D) Ansible Operations Workshop

Reviewed: 2026-09-04

## What is this asset?

This workshop enables OCI users to run Exadata Database Service on Dedicated Infrastructure (ExaDB-D) with Ansible with IaC and how to run using GitOps at scale. 

It includes Provisioning, Change, Maintenance, and Backup & Recovery and High Availability Operations with OCI Ansible Collection and regular playbooks.

For Cloud Operators, Admins, Architects, DevOps and Center of Excellence teams.

Use it to know more about ExaDB-D characteristics and typical Day 1 and Day 2 operations.

## How to use this asset?

Read in the files folder the workshop in PDF [ExaDB-D - Ansible Operations Deep Dive Worksho.p](./files/Public_5_ExaDB-D_Ansible_Operations_v0.3.pdf).

Use the supporting Ansible playbooks included in the file [oci-ansible-collection_v0.3.tar.gz](./files/oci-ansible-collection_v0.3.tar.gz) on your own when commented in the examples.

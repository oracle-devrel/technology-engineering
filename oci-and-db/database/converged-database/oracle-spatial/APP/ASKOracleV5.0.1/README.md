# Ask Oracle Select AI Chatbot — Spatial, Graph, and Agents

Use this asset as a reference for deploying the Ask Oracle Select AI application with interactive Spatial and Graph visualizations and Select AI Agent teams in Oracle APEX. The app can be configured for different datasets and builds on the earlier Ask Oracle 5.0.1 work. The supplied application export identifies itself as **Release 5.0.0.1**, was generated by **APEX 26.1.5**, and includes the **Graph Visualization plug-in 26.1.6**. Reviewed: 2026.11.04

## When to use this asset?

Use this app to ask natural-language questions and inspect returned results in a chat interface. It can display points, lines, and polygons on a map, style mapped features by their returned attributes, and show graph results through the Graph Visualization plug-in. The app also provides an Agent Team selector for routing requests to database-defined Select AI Agents. The available answers depend on the profiles, teams, tools, and datasets installed in the connected database.

## How to use this asset?

This folder contains the APEX application export and a separate backup of its static application files:

- `f121.zip` — application 121 export (`f121.sql` inside). The application export includes its static application files, application processes, and plug-in definitions.
- `f121_static_application_files.zip` — separate copy of the static application files, including the map, styling, analysis, and graph JavaScript and CSS.

1. Import `f121.zip` in **APEX App Builder → Import** and select the target parsing schema. Review the installation options and supporting objects before installing.
2. Confirm that application 121, its application processes, static application files, and **Graph Visualization plug-in 26.1.6** were imported. The static-files ZIP is a backup; upload files from it only if they are missing after import.
3. Connect the app to a database containing the required tables, Select AI profiles, Agent teams, tools, and any supporting database objects used by the selected features. The APEX export does not recreate those database analyses or their saved results.
4. Test one spatial question that returns GeoJSON, one Agent Team request, and one graph request. Check that the map styling panel can color returned points or polygons by an attribute.

The application expects map geometry as GeoJSON in WGS 84 (EPSG:4326). Source geometries may remain in their original coordinate system in the database and must be transformed when producing map results.

Ready to start? Use the [tree and neighbourhood dataset and workflow](https://github.com/oracle-devrel/technology-engineering/tree/maryam-04_09_26/oci-and-db/database/converged-database/oracle-spatial/SpatialAI/Buurt_tree) as a working example.

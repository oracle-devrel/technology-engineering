# Migrate legacy character encoding to Unicode
 
Leverage Oracle's Database Migration Assistant for Unicode (DMU) to make character set migrations easier and less manual. DMU is a next-gen migration tool that streamlines the entire migration process with an intuitive GUI that minimizes the DBA’s manual
workload and decision-making. It helps ensure all migration issues are addressed beforehand and the conversion of data is
carried out correctly and efficiently.

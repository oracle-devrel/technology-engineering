# SODA Import utility
 
This directory contains utility developed in Java, which can be used to import JSON documents directly to a JSON collection table by using SODA driver for Java

Review Date: 29.07.2026

# When to use this asset?
 
Use this asset when you need to upload json file containing multiple json documents into a JSON collection table or want to demonstrate Java support for SODA
 
# How to use this asset?
 
To use this asset there is need to install JDK v. 25 or newer, download Java code from files directory, modify username, password and connection string, compile and run against an existing Oracle Database 26ai

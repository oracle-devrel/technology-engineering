# Autonomous Database JSON NFS demo
 
Demonstration of working with JSON documents stored on a NFS mountpoint from the level of an Oracle AI Autonomous Database

Review Date: 31.07.2026

# When to use this asset?
 
Use this asset to demonstrate how to mount an NFS share and work on JSON documents stored in this share from the level of an Autonomous Database
 
# How to use this asset?
 
Edit and run adb_json_nfs_external_tables.sql being connected to an Autonomous Oracle Database.

# MongoDB Replay
 
This is the Java program, which can be used to demonstrate how to replicate commands from original MongoDB database to Oracle API for MongoDB instance and - at the same time - get the detailed information about incompatibilities

Review Date: 29.07.2026

# When to use this asset?
 
Use this asset to demonstrate command replication between a MongoDB database and Oracle API for MongoDB
 
# How to use this asset?
 
To use this asset there is need to download the content of bin directory and configure extractor and applier applications
Detailed instructions about configuration of these components can be found in doc folder

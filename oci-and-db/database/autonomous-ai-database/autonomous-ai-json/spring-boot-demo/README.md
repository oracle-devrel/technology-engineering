# Spring Boot Demo for Oracle API for MongoDB
 
This is the short demo proving that Oracle API for MongoDB supports native MongoDB applications using SpringBoot framework

Review Date: 31.07.2026

# When to use this asset?
 
Use this asset as an example, when you want to demonstrate support for native MongoDB applicatons developed by using SpringBoot framework
 
# How to use this asset?
 
Prerequisites
- Oracle Database 26ai with MongoDB API enabled
- JDK 25 or later
- SpringBoot framework
- Any Java IDE supporting SpringBoot framework
To use this demo there is need to provide real username, password and connection string to connect to an Oracle API for MongoDB instance.
After that - simply run the application.

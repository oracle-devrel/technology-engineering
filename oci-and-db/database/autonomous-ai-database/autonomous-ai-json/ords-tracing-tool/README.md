# ORDS Tracing Tool
 
This directory contains ORDS Tracing PL/SQL tool

Review Date: 03.08.2026

# When to use this asset?
 
Use this asset when there is need to trace ORDS activity at the level of an Oracle Database

# How to use this asset?
 
This tool has been developed in form of a PL/SQL package - it needs to be installed and used at the level of an Oracle Database. Detailed instructions can be found in files/doc directory

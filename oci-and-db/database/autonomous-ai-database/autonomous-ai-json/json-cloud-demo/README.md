# JSON Cloud Demo
 
This repository contains a demonstration how to work on JSON documents stored in an Object Storage bucket from the level of an Oracle Database

Review Date: 31.07.2026

# When to use this asset?
 
Use this asset to demonstrate how to work on external JSON documents, stored in an Object Storage bucket from the level of an Oracle Database

# How to use this asset?

To use this asset there is need to run utl_json_cloud.pls and utl_json_cloud.plb scripts to create UTL_JSON_CLOUD PL/SQL package. After that - edit and run demo.sql script.

# Basic Oracle API for MongoDB demo in Java
Sample code, which uses Java MongoDB connector to connect to Oracle API an for MongoDB and perform simple document operations

Review Date: 29.07.2026

# When to use this asset?
This asset can be used to demonstrate Oracle API for MongoDB support for Java developers

# How to use this asset?
Requirements
* JDK v. 25 or higher
* (Optional) Any Java IDE, like NetBeans, Idea IntelliJ or Oracle Java Developer
* Oracle Database 26ai with Oracle API for MongoDB configured
To use this asset there is need to download the content of files directory, modify Main.java by providing real connect string, username and password, compile and run it

# Onboarding activation runbook for Oracle AI Database@AWS

This document is a customer onboarding guide and activation checklist covering AWS Marketplace purchasing, OCI tenancy linking, AWS and OCI prerequisites, and database provisioning, for Oracle AI Database@AWS.

Reviewed: 29.09.2026

# When to use this asset?

Anyone working with Oracle AI Database@AWS can use this guide before and during activation process. It helps confirm buyer and deployment accounts, identify permission or policy blockers, and plan subscription sharing where needed.

# How to use this asset?

Customize the details, select the relevant service journey, and complete the questionnaire with named owners. Confirm account permissions, OCI access, network design, and database sizing. Follow the checklist through offer acceptance, tenancy linking, optional AWS License Manager subscription sharing, provisioning, and support and monitoring setup.

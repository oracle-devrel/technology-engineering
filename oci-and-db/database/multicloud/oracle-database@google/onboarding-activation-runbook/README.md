# Onboarding activation runbook for Oracle AI Database@GCP

This document is a customer onboarding guide that coordinates Google Cloud Marketplace activation, billing account and project selection, OCI tenancy linking, and technical deployment readiness, for Oracle AI Database@GCP.

Reviewed: 13.10.2026

# When to use this asset?

Anyone working with Oracle AI Database@GCP can use this guide when preparing and executing onboarding. It also supports discussions about public-to-private offer transitions, additional projects, and Shared VPC requirements.

# How to use this asset?

Customize the runbook and complete the questionnaire with the responsible owners. Review billing account, project, and OCI tenancy decisions, then confirm access, networking, and database requirements. Use the applicable service journey and activation checklist to coordinate offer acceptance, tenancy linking, provisioning, and support readiness.

# Oracle Database@Google Cloud Design Workshop

A workshop designed to provide an overview of the Oracle Database@Google Cloud solution, the supporting solution definition documents (SDD), and the related reference materials for customers and partners.

Reviewed: 28.07.2026

# When to use this asset?

Use this workshop to understand the Oracle Database@Google Cloud solution in more detail and to access the supporting design materials and documentation.

The workshop content is organized into a set of supporting materials. Review the solution definition document and the related reference materials in the files folder to understand the service options and deployment context.

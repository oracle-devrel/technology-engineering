# Onboarding activation runbook for Oracle AI Database@Azure

This document is a customer onboarding guide and working checklist covering Azure Marketplace offer acceptance, OCI tenancy linking, technical readiness, and database provisioning, for Oracle AI Database@Azure.

Reviewed: 14.10.2026

# When to use this asset?

Anyone working with Oracle AI Database@Azure can use this asset before and during onboarding. It helps identify the correct Azure tenant and subscriptions, assign responsibilities, and resolve prerequisites before activation.

# How to use this asset?

Customize the details and retain the relevant database service journeys. Complete the onboarding questionnaire, confirm permissions and network requirements, and agree on the deployment plan. Follow the activation checklist to track Marketplace acceptance, tenancy linking, provisioning, and operational readiness.

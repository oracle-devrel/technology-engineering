# Preview this asset on GitHub

This folder is prepared for GitHub, but it is not published yet. To review the rendered README before sharing it publicly:

1. Download and unzip `aidp-visual-builder-external-tools-github.zip`.
2. Create a **private** draft repository on GitHub.
3. Open the repository and choose **Add file → Upload files**.
4. Drag the unzipped `aidp-visual-builder-external-tools` folder into the upload area (or select its files) so GitHub keeps its folders and `README.md` is at the repository root. Do not upload only the ZIP; GitHub will not render a README inside the archive.
5. Commit to a draft branch or the private repository, then open `README.md` and click through the links to review the setup.
6. Add screenshots only after hiding gateway/API details and private data. Upload each under `images/screenshots/` with the filename in the guide.
7. When the page looks right, change the repository visibility or move the files to your intended public asset repository.

GitHub's [upload instructions](https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository) explain the browser upload flow. The web uploader accepts up to 100 files at a time and limits each file to 25 MiB.

Before making a repository public, check that no file or screenshot includes credentials, API gateway URLs, endpoint paths/IDs, private catalog names, or company/customer data.

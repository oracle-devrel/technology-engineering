# Test evidence

The screenshots in `../..` document the existing demo flow, a completed vector-store file list, and a Playground session. They do not prove a new customer's database credentials, tool configuration, API key, or deployed endpoint.

The Custom Tool source is packaged without credentials. Before using the tutorial in a customer environment, follow each setup step and record three checks: Select AI query succeeds through the Custom Tool; vector search returns a relevant passage; the combined Playground trace shows both tools and the answer matches their results. Deploy only after these checks pass.

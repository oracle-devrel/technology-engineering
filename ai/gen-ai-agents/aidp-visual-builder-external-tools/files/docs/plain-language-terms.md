# Plain-language terms

- **Structured data:** information arranged in tables, such as dates, scores, and delivery status.
- **Document search / RAG:** finding relevant parts of uploaded files before the agent writes an answer.
- **Vector store:** the service that holds searchable document chunks.
- **Ingest/index:** preparing uploaded files so they can be searched.
- **Credential Store:** AIDP’s place to keep passwords and API keys outside the source code.
- **Egress:** the list of outside services the AIDP compute is allowed to reach.
- **Trace:** the record showing which agent tools ran for a chat.
- **Evidence:** records or documents that support a statement.

  Routes:
    /        → Frontend (React SPA)

Pre-requisites (created outside Helm):
  1. OCIR pull secret:
     kubectl create secret docker-registry {{ .Values.registry.pullSecret }} \
       --docker-server={{ .Values.registry.server }} \
       --docker-username='<namespace>/<user>' \
       --docker-password='<auth-token>' \
       --docker-email='<email>' \
       -n {{ .Values.namespace }}

  2. Oracle wallet secret:
     kubectl create secret generic {{ .Values.backend.oracleWalletSecret }} \
       --from-file=backend/config/wallet/ \
       -n {{ .Values.namespace }}
